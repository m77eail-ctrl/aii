# التقنية والأناقة AI

دليل عربي تفاعلي يتضمن **250 مدخلًا أوليًا** موزعًا بالتساوي على خمسة أقسام. يعمل في المتصفح دون خادم.

## التشغيل

افتح `index.html` في المتصفح مباشرة. يعمل البحث والتصفية والمفضلة والمقارنة وإضافة الأدوات وإدارة البيانات محليًا عبر LocalStorage. يحتاج عرض أيقونات المواقع إلى اتصال إنترنت.

## النشر على GitHub Pages

ارفع جميع الملفات الموجودة في هذا المجلد إلى مستودع GitHub عام، ثم اختر Settings → Pages → Deploy from a branch → main / root. سيكون الموقع ثابتًا وبدون خادم.

## تنبيهات مهمة

- الأدوات الـ250 **قائمة أولية** لأسماء وروابط معروفة؛ لم يتم إجراء فحص مباشر شامل للروابط أو حالة الخدمات أو الأسعار في يوم النشر. يجب مراجعتها قبل اعتبار الدليل موثقًا.
- أضيفت تصنيفات الاشتراك (مجاني، مجاني ومدفوع، مدفوع، غير محدد). معظمها تقديرات أولية وليست مراجعة مباشرة حديثة؛ تظهر علامة ✓ فقط للتصنيفات التي تمت مراجعتها عبر صفحات رسمية، مع مصدر مرجعي داخل التفاصيل. قد يتغير نموذج التسعير، لذا ينبغي مراجعة الموقع الرسمي لكل أداة.
- لوحة الإدارة المحلية ليست نظام إدارة آمنًا متعدد المستخدمين. التغييرات محفوظة في المتصفح الذي يجري التعديل فقط. لبيئة إنتاج مشتركة، يلزم Backend حقيقي وقاعدة بيانات ونظام حسابات وصلاحيات.
- بعض الأدوات تصنف في أكثر من قسم بطبيعتها؛ تم إدراجها ضمن قسم أساسي واحد وتوجد أسماء قد تتكرر عبر فئات مختلفة.
- الأيقونات تُسترجع من خدمة favicons عامة وليست شعارات محفوظة ضمن المشروع.
- لا توجد مدفوعات أو اشتراكات أو نظام تتبع زيارات.

## الملفات

- `index.html`: صفحة الموقع
- `style.css`: المظهر المتجاوب
- `app.js`: التفاعل والبحث والفلاتر والمقارنة والإدارة المحلية
- `data.js`: بيانات أساسية مضمنة للعمل دون خادم
- `data.json`: نسخة JSON من بيانات الأدوات
- `categories.json`: أسماء الأقسام
